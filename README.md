                                                      Proto Man Mode Deluxe

A Mega Man 2 NES ROM hack inspired by Proto Man’s gameplay in Mega Man 9 and 10, featuring charging, sliding, airborne shield mechanics, updated graphics, presentation changes, and three gameplay variants.

Release files are provided as IPS patches only. No ROM is included.
